Cómo funciona
🌐 Accedé desde cualquier dispositivo en guillermofissore.github.io/ypf-dashboard/Dashboard_Clover_YPF_v2.html · Contraseña: ypf2229
💾 Los datos se guardan automáticamente en el navegador. Usá Exportar backup para llevar los datos entre dispositivos.
1
Dos formatos de Clover compatibles
Formato A — Resumen por medio de pago: Clover → Reportes → Información general de las ventas → Exportar CSV.
Formato B — Pagos individuales (Payments): Clover → Reportes → Pagos → Exportar CSV. Contiene cada transacción con hora, tarjeta, estado, nota QR, etc.
El dashboard detecta automáticamente cuál es cuál al cargarlo.
Formato A: columnas → Medio de pago | Total de ventas brutas | Devoluciones
Formato B: columnas → Fecha del pago | ID del pago | Marca de la tarjeta | Importe | Resultado
2
Cargar Clover (pestaña 📂 Clover)
Arrastrá o seleccioná el CSV. Podés cargar varios archivos uno a uno — se acumulan. El sistema agrupa por día de venta y calcula aranceles, IVA y fechas de acreditación por días hábiles.
3
Buscar transacciones individuales (pestaña 🔎 Transacciones)
Solo disponible con Formato B. Buscá por importe, tarjeta, comprobante, QR ID, cliente o fecha. Podés ver las rechazadas (FAIL) separadas.
4
Cargar extracto del banco (pestaña 🏦 Banco)
CSV del homebanking BNA — Últimos movimientos → Exportar CSV. Columnas: Fecha, Comprobante, Concepto, Importe.
5
Verificar acreditaciones (pestaña ✅ Verificación)
Cruza automáticamente Clover vs banco por fecha y monto. Te dice si calza, si está pendiente (fecha futura) o si hay diferencia.
